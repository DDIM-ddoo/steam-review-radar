# Steam 리뷰 기획 레이더

Steam 플레이어 리뷰를 게임 요소 단위로 분석해 신규 게임의 기획 방향을 **강화할 것 / 피할 것 / 사전 검증할 것**으로 정리하는 웹 대시보드입니다. 유료 API 없이 동작합니다.

- 설계 문서: [design-doc.pdf](design-doc.pdf)
- 첫 화면에는 예시 분석(소울라이크, Claude로 분석한 결과)이 열립니다. 왼쪽에서 태그나 게임을 고르면 새 분석을 직접 실행할 수 있습니다.

## 분석 흐름
1. Steam 태그 조합으로 대상 게임을 고릅니다(평가 낮은 게임 약 30% 포함, 생존 편향 완화).
2. 서버가 게임별 리뷰를 수집하고, 브라우저가 너무 짧거나 내용 없는 리뷰를 제거합니다.
3. **규칙 기반 엔진**이 리뷰를 문장으로 나눠 24개 게임 요소(조작감, 최적화, 가격 등)의 긍정·부정 의견을 찾습니다. 요소 키워드 사전과 한·영 감성 사전, 부정어 처리를 씁니다.
4. 요소별 순감성, 평가 상위·하위 게임 비교, 플레이 시간 구간 비교, 워딩 통계(로그 오즈비)를 계산합니다.
5. 집계 결과에 정해진 규칙을 적용해 시사점을 만들고, 근거 리뷰를 붙입니다. 요청 표현("~했으면", "please add")은 패턴으로 찾아 요소별로 묶습니다.

## 기획 방향 도출 (결론)
우측 상단 **기획 방향 도출** 버튼을 누르면, 분석 데이터를 동종 장르 신작의 기획 방향 5가지로 정리합니다. 장르 분석과 특정 게임 분석 모두에서 동작합니다.

| 방향 | 출발점이 되는 데이터 |
|---|---|
| 1. 최대 강점 극대화 | 언급이 많고 칭찬이 우세한 요소, 평가 상위·하위 게임 차이 |
| 2. 1순위 불만 해결 | 비추천 리뷰에서 가장 많이 지적된 요소 |
| 3. 미충족 요구 공략 | 리뷰에서 반복되는 요청("~했으면") |
| 4. 장기 플레이 설계 | 플레이 시간이 길수록 평가가 떨어지는 요소, 동접 유지율이 낮은 게임의 불만 |
| 5. 첫 2시간 진입 장벽 낮추기 | 2시간 미만 플레이 리뷰의 불만 |

각 방향에는 한 줄 컨셉, 근거 수치, 핵심 설계 원칙, 반드시 피할 것, 출시 전 검증할 것, 타깃 플레이어, 벤치마크 게임, 리스크, 근거 리뷰가 붙습니다. 한 요소는 한 방향에만 쓰이며, 근거가 약한 방향은 "근거 약함"으로 표시합니다. 방향을 선택하고 보고서(Markdown)로 내보낼 수 있습니다.

**이 방향 선택**을 누르면 기획서 첫 장 형태의 **콘셉트 시트**가 열립니다. 한 줄 콘셉트, 핵심 경험, 기둥 3개, 플레이어가 구체적으로 말한 문제(핵심 요소를 언급한 문장에서 유독 많이 나온 표현), 함께 풀어야 할 문제(같은 리뷰에서 함께 불만으로 나온 요소와 그 배율), 하지 않을 것, 설계 원칙, 타깃 플레이어(리뷰어 플레이 시간·추천 비율 등 데이터 윤곽), 경쟁 포지션, 분석 데이터를 기준선으로 한 성공 지표, 리스크를 담으며 Markdown으로 내보낼 수 있습니다.

## 판매·동시 접속 지표
리뷰 분석에 치우치지 않도록 객관 지표를 함께 보여 줍니다. 추정치는 쓰지 않습니다.

| 항목 | 출처 |
|---|---|
| 정가 | Steam 스토어 현재 한국 정가 |
| 실제 판매량·실제 매출 | 개발사·퍼블리셔가 직접 발표한 수치만. 인정 출처는 ① 회사 보도자료·IR 자료 ② 게임·회사 공식 SNS 계정 ③ Steam 공식 게임 페이지 뉴스. 출처 종류·발표 주체·발표일·발표 범위를 함께 표시. Steam은 게임별 판매량을 공개하지 않으므로 발표가 없으면 "공식 발표 없음" |
| SteamSpy 보유자 | SteamSpy의 보유자 수 추정 구간(공식 수치 아님) |
| 동접 최근 30일 평균, 역대 최고 | SteamCharts 기록 |
| 동접 유지율 | 최근 30일 평균 ÷ 출시 후 첫 3개월 중 최고 월평균 |

기본으로 들어 있는 공식 발표치: ELDEN RING NIGHTREIGN 500만 장 이상(KADOKAWA 보도자료, 2025-07-24, 전 플랫폼 출하량), Black Myth: Wukong 1,000만 장(Game Science 공식 X, 2024-08-23, 전 플랫폼). Mistfall Hunter는 플레이어 수만 발표되어 "공식 발표 없음".

## 원문 번역 (영어·중국어 → 한국어)

- 리뷰 원문이 실리는 곳(요약 근거 리뷰, 워딩, 숨은 요구, 리뷰 탐색기, 기획 방향 근거, 콘셉트 시트)에 번역 기능이 붙습니다.
- 화면 맨 위 **한국어로 번역**: 모든 화면의 원문을 번역합니다(켜 두면 다음 접속에도 유지).
- 파트마다 **번역** 버튼: 그 부분만 번역합니다. 번역문 아래에 원문을 작게 함께 보여 줍니다.
- 무료 공개 번역(Google 번역 웹 엔드포인트, 실패 시 MyMemory)을 `api/translate.js`가 중계합니다. API 키와 비용이 없습니다. 무료 서비스라 요청이 몰리면 잠시 거절될 수 있고, 그때는 원문이 그대로 남습니다.
- 번역 결과는 브라우저에 저장해 같은 문장을 다시 요청하지 않으며, 보고서·콘셉트 시트 내보내기에도 "(번역: …)"으로 함께 실립니다.
- 중국어(간체) 리뷰도 요소·감성 사전으로 분석합니다.

## 규칙 엔진의 정확도
Claude가 요소별로 분석한 한국어 리뷰 300건을 기준으로 비교했습니다.
- 요소 찾기: 정밀도 65.4%, 재현율 69.4% (F1 67.4%)
- 같은 요소를 찾았을 때 긍정·부정 판정 일치: 74.9%

키워드 사전은 이 표본을 보며 보정했으므로, 다른 장르나 언어에서는 정확도가 더 낮을 수 있습니다.

## 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체(대시보드, 차트, 규칙 기반 분석 엔진, 통계 계산) |
| `api/steam.js` | Steam 공개 데이터 중계(허용된 경로만) |
| `api/stats.js` | 판매·동시 접속 지표 수집(Steam API, SteamCharts, SteamSpy, Steam 스토어) |
| `api/translate.js` | 영어·중국어 원문 → 한국어 무료 번역 중계 |
| `api/health.js`, `api/_auth.js` | 서버 상태 확인, 선택적 접근 코드 |

GitHub 저장소를 Vercel에 연결하고 Deploy만 누르면 됩니다. 환경 변수는 필요 없습니다.
수집 서버를 아는 사람만 쓰게 하려면 `ACCESS_CODE` 환경 변수를 설정하세요(선택).

분석 결과는 사용자의 브라우저(localStorage)에 저장됩니다.
