# Steam 리뷰 기획 레이더

Steam 플레이어 리뷰를 게임 요소 단위로 분석해 신규 게임의 기획 방향을 **강화할 것 / 피할 것 / 사전 검증할 것**으로 정리하는 웹 대시보드입니다. 유료 API 없이 동작합니다.

- 설계 문서: [design-doc.pdf](design-doc.pdf)
- 첫 화면에는 예시 분석(소울라이크, Claude로 분석한 결과)이 열립니다. 왼쪽에서 태그나 게임을 고르면 새 분석을 직접 실행할 수 있습니다.

## 분석 흐름
1. Steam 태그 조합으로 대상 게임을 고릅니다(평가 낮은 게임 약 30% 포함, 생존 편향 완화).
2. 서버가 게임별 리뷰를 수집하고, 브라우저가 너무 짧거나 내용 없는 리뷰를 제거합니다.
3. **규칙 기반 엔진**이 리뷰를 문장으로 나눠 24개 게임 요소(조작감, 최적화, 가격 등)의 긍정·부정 의견을 찾습니다. 요소 키워드 사전과 한·영 감성 사전, 부정어 처리를 씁니다.
4. 요소별 순감성, 평가 상위·하위 게임 비교, 플레이 시간 구간 비교, 워딩 통계(로그 오즈비)를 계산합니다.
5. 집계 결과에 정해진 규칙을 적용해 시사점을 만들고, 근거 리뷰를 붙입니다. 요청 표현("~했으면", "please add")은 패턴으로 찾아 요소별로 묶습니다.

## 규칙 엔진의 정확도
Claude가 요소별로 분석한 한국어 리뷰 300건을 기준으로 비교했습니다.
- 요소 찾기: 정밀도 65.4%, 재현율 69.4% (F1 67.4%)
- 같은 요소를 찾았을 때 긍정·부정 판정 일치: 74.9%

키워드 사전은 이 표본을 보며 보정했으므로, 다른 장르나 언어에서는 정확도가 더 낮을 수 있습니다.

## 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체(대시보드, 차트, 규칙 기반 분석 엔진, 통계 계산) |
| `api/steam.js` | Steam 공개 데이터 중계(허용된 경로만) |
| `api/health.js`, `api/_auth.js` | 서버 상태 확인, 선택적 접근 코드 |

## 배포 (Vercel, 무료)
GitHub 저장소를 Vercel에 연결하고 Deploy만 누르면 됩니다. 환경 변수는 필요 없습니다.
수집 서버를 아는 사람만 쓰게 하려면 `ACCESS_CODE` 환경 변수를 설정하세요(선택).

분석 결과는 사용자의 브라우저(localStorage)에 저장됩니다.
